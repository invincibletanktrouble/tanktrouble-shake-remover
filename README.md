# TankTrouble Shake Remover

A lightweight userscript that completely removes all camera shake and viewport vibration caused by tank explosions, mines, and hazards in **Tank Trouble**.

## Features

- **Zero Camera Shake:** Keeps the maze borders and viewport completely still during kills and explosions.
- **Engine-Level Patching:** Dynamically neutralizes Phaser camera shake without breaking game physics or multiplayer synchronization.
- **Automatic Updates:** Works seamlessly across game rounds and reconnects.

## Installation

1. Install a userscript manager like [Tampermonkey](https://www.tampermonkey.net/).
2. Click here to install: **[Install Script](https://raw.githubusercontent.com/invincibletanktrouble/tanktrouble-shake-remover/main/TankTrouble-Shake-Remover.user.js)**
3. Confirm the installation prompt in Tampermonkey.
4. Open [Tank Trouble](https://tanktrouble.com) and play.
